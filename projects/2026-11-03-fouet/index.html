How to crack

  • Click in a field first: orange pixel corners mark it. Only that field gets typed into, at your cursor.
  • Accelerating never cracks. Braking does: swing hard, then stop dead or flick back.
  • The crack lands one whip-length ahead, where the lash is thrown — aim it onto the marked field.
  • 3 hits in a row → LOUDER! · 6 hits → MAXIMUM!!!
  • Esc puts the whip away. Cracking anywhere else only makes sparks.

On your desktop (Windows)

The same whip, over every app: Teams, VS Code, Outlook, your browser… No Python, no admin rights needed.

⬇ FouetSetup.exe installer · 12 MB ⬇ Fouet.exe portable · 11 MB
  1. Run FouetSetup.exe: it adds Fouet to the Start menu, can start it with Windows, and uninstalls from Settings › Apps. Or just run the portable Fouet.exe from anywhere.
  2. Windows SmartScreen may warn about an unknown publisher (the app isn't code-signed): click More info › Run anyway.
  3. Click in a text field of any app (orange pixel corners appear around it), then click the pixel button bottom-right (or Ctrl+Alt+W). Swing hard, stop dead: if the tip cracks on that field, Fouet types the phrase at your text cursor. It never clicks anywhere.
  4. Esc puts the whip away · right-click the button for Start with Windows and Quit.

Prefer Python? Download fouet.py (single file, standard library only) and run py fouet.py. The overlay is click-through: your mouse keeps working normally while the whip is out.
